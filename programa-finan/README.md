# 💰 Projetos de Simulação Financeira com Python

## 📝 Descrição

Este repositório reúne uma coleção de projetos desenvolvidos em Python com foco em **automação financeira, análise de investimentos, manipulação de planilhas Excel e visualização de dados**.

Os projetos foram criados com o objetivo de aplicar conceitos práticos de programação, matemática financeira e análise de dados em cenários reais de investimento.

Ao longo dos códigos, são explorados temas como:

- Juros compostos
- Evolução patrimonial
- Simulação de aportes mensais
- Comparação de ativos financeiros
- Criação e manipulação de planilhas Excel
- Geração de gráficos para análise financeira

---

## 🚀 Tecnologias Utilizadas

- **Python 3.x**
- OpenPyXL
- Pandas
- NumPy
- Matplotlib
- Plotly
- yFinance

---

## 📂 Estrutura dos Projetos

### 1. `criacaoplanilha.py`

Sistema de automação financeira que cria uma planilha Excel contendo clientes, valores investidos, taxas de juros e cálculo automático de juros compostos.

**Principais conceitos:**

- Manipulação de Excel
- Automação de processos
- Juros compostos

---

### 2. `evolucaoinvest.py`

Simulação da evolução de investimentos ao longo do tempo, considerando aportes mensais e rendimento composto.

**Principais conceitos:**

- Crescimento patrimonial
- Simulação de aportes
- Visualização gráfica

---

### 3. `evolucaosaldoerend.py`

Sistema que calcula separadamente o saldo acumulado e o rendimento obtido mês a mês.

**Principais conceitos:**

- Rentabilidade
- Comparação de crescimento
- Exportação de dados

---

### 4. `planilhacomgrafico.py`

Aplicação que coleta dados reais do mercado financeiro, simula investimentos em ações e gera gráficos dentro de planilhas Excel.

**Principais conceitos:**

- Dados da bolsa de valores
- APIs financeiras
- Análise de ativos

---

### 5. `grafico_app.py`

Sistema interativo que compara ações de bancos brasileiros utilizando dados históricos reais do mercado.

O usuário escolhe dois bancos e o sistema gera um gráfico comparativo da evolução de um investimento.

**Principais conceitos:**

- Comparação de ativos
- Diversificação de carteira
- Visualização interativa

